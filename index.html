标题名称

把设计图直接拖进页面就能批量新建视图，拖到某个区域上可替换该区域切图，也可以 ⌘V 粘贴截图； 按 H 拖拽画热区，P 预览点击效果，? 查看全部快捷键。改动会自动保存在本浏览器。

添加热区中：在顶栏、内容区或输入区上按住拖拽画出热区（单击放置默认大小），可连续添加。按 Esc 或 H 结束。
还没有视图 把一张或多张设计图拖到这里即可批量新建视图（按文件名排序，“01_首页.png”会自动识别编号）
或点击右侧「＋ 新增视图」
自动保存已开启
新增视图
小技巧：直接把多张图片拖进页面空白处，可一次批量新建多个视图，不用逐个点。
快捷键与使用说明
放图
拖图到空白处
批量新建视图（按文件名排序，“01_首页.png”自动识别编号和名称）
拖图到某区域
替换顶栏 / 内容区 / 输入区的切图；拖到视图其它位置则整屏替换
⌘V
粘贴剪贴板截图：贴到鼠标所在区域；鼠标不在视图上时新建视图
多层叠加
内容区的「图层」按钮可叠加多张固定层，只有顶层滚动；或按住 ⌥ 拖图到内容区直接添加固定层
热区
H
开始 / 结束添加热区，按住拖拽画框，可连续添加
单击热区
设置跳转目标（默认自动指向下一个视图）；拖动移动，拖右下角调整大小
Delete
删除选中热区
方向键
微调位置 1px，按住 Shift 移动 10px
⌘C / ⌘V
复制热区，鼠标移到其它视图的区域上粘贴（位置不变，适合统一的返回/导航按钮）
⌘D
原地复制一个热区
其它
⌘Z / ⌘⇧Z
撤销 / 重做（删除视图、换图等都能撤销）
P
预览模式：在总览里直接点热区跳转，点空白处高亮可点区域
▶ 演示模式
单手机全屏演示，←→ 切换视图，⌫ 返回上一页，Esc 退出
⠿ 拖动
拖动视图名称左侧的 ⠿ 调整视图顺序
自动保存
所有修改实时保存在当前浏览器，刷新不丢；换电脑或备份请用「导出可编辑版」
热区设置
紫色虚线框已显示在手机内，可拖动位置，拖右下角调整范围大小。
修改即时生效 · 拖动可移动 · 拖右下角调整大小 · Delete 删除
内容区图层
只有顶层随页面滚动，热区跟随顶层；固定层始终停在原位。顶层需为透明 PNG 才能透出下方图层。也可按住 ⌥ 把图片拖到内容区，直接添加为固定层。
视图列表
点击热区跳转 · 点击空白处会闪烁提示可点区域 · ← → 切换视图 · ⌫ 返回 · Esc 退出
