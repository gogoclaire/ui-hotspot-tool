# UI 原型热区交互工具

一个纯前端单文件原型设计图热区跳转工具，支持批量导入设计图、拖拽画热区、多层固定/滚动图层叠加、全屏演示模式、本地自动保存与演示版 HTML 导出。

## 在线访问

部署在 GitHub Pages：`https://gogoclaire.github.io/ui-hotspot-tool/`

## 主要功能

- **批量放图**：直接拖拽多张设计图到页面空白处批量新建视图，或拖到指定区域替换切图，也支持 `⌘V` 粘贴截图。
- **内容区多层叠加**：点击内容区右上角「图层」（或按住 `⌥ Option` 拖图），可叠加多个不滚动的固定层，仅最顶层随页面滚动。
- **热区交互**：按 `H` 拖拽绘制热区，支持多级页面跳转与返回上一页、`⌘C` / `⌘V` 跨视图原位复制、方向键微调。
- **预览与演示**：按 `P` 预览点击跳转，或进入全屏「演示模式」。
- **本地保存与双导出**：改动自动保存在浏览器 IndexedDB 中，支持导出演示版 HTML 与可编辑版 HTML。
